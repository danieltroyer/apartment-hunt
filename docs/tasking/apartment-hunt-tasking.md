App: Apartment Hunt
Goal: Help me find the right apartment to rent
Tasks:
1. Identify target geography
2. Identify basic apartment preferences
3. Query various sources for current apartment listings that match the basic preferences (including Craigslist, Zillow, Apartments.com, local property managers)
4. Present listings for user interaction
5. Gather user feedback about each listing 
   - Create a .md file for each listing in a subdirectory in the format /[date]/[listing_id].md
   - Store identifiable information about each listing, like address, price, number of bedrooms, source, and a brief description
   - Store user feedback (like/dislike, comments)
   - Store user preferences for future searches
6. Refine search based on user feedback
7. Repeat steps 3-6 until a suitable apartment is found or user decides to stop
